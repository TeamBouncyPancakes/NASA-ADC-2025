# Antenna Object Files
**DSN_34 *Deep Space Network Antenna 34***: Main antenna for the Deep Space Network  
**RV *Reduced Vertices***: DSN_34 with reduced vertices  
**MRV *More Reduced Vertices***: RV but with even more reduced vertices  
**SMRV *Smaller More Reduced Vertices***: MRV but a smaller size  
**DSN_70 *Deep Space Network Antenna 70***: Secondary antenna model  
  
These object files are used in the code for Team *Bouncy Pancakes*' submission for the 2025 NASA App Development Challenge.
